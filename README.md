B# Brain Tumor Detection Web App

**Live Demo:** [Click here to view the deployed app](https://brain-tumour-detection-npnbxzfgxzjjjquwlvvrer.streamlit.app/)

---

## About The App

This web application uses a fine-tuned YOLO object detection model to identify and locate brain tumor regions in MRI scans. 

Users can upload an MRI scan in JPG, JPEG, or PNG format, click a button, and view the visual detection results alongside a summary of the identified regions.

---

## How to Use

1. Open the [Live Demo](https://brain-tumour-detection-npnbxzfgxzjjjquwlvvrer.streamlit.app/).
2. Upload a brain MRI scan using the sidebar file uploader.
3. Click **Predict Tumor** to view the bounding box detection on the MRI image.
